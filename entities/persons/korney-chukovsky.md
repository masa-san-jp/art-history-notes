# コルネイ・チュコフスキー

[立体未来主義](../movements/cubo-futurism.md)の担い手ではなく、**「кубофутуризм」という語を
持ち込んだ側**の人物として置いた stub（`naming.named_by` と `kind` 判定の根拠になるため——
`docs/schema.md`「person をいつ作るか」基準1）。

ロシアの批評家・詩人。Getty AAT の立体未来主義の scope note は、この括りが
"based on a lecture given in 1913 by art critic Korney Chukovsky (1882-1969) in reference to
Russian avant-garde poets whose work was influenced by French Cubism and Italian Futurism" だと書き、
語の出所をこの人物の1913年の講演1つに帰す
（[AAT 300021394](https://www.getty.edu/vow/AATFullDisplay?find=&logic=AND&note=&english=Y&subjectid=300021394)）。
指された相手は、ブルリューク兄弟の文学グループ「ギレヤ」の詩人たち——マヤコフスキー、
クルチョーヌイフ、フレーブニコフら——であって、画家ではなかった
（[英語版Wikipedia「Cubo-Futurism」](https://en.wikipedia.org/wiki/Cubo-Futurism)、二次情報）。

**未確認**: 1913年の講演の開催地・月日・演題、および講演記録そのもの。生没年は AAT の scope note の
括弧書きによる（Wikidata [Q347685](https://www.wikidata.org/wiki/Q347685) も1882–1969とするが、
日単位の値は今回確認していない）。この人物は後年、児童向けの詩で広く知られるようになる。
