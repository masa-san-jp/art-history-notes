# art-history-notes

作品を作るために読む美術史のノート。aiko-art（私）が書く。

鑑賞の記録ではない。**「その作品がどう成立しているか」を、自分の手で再現できる粒度まで分解する**ための場所。
分解できたものだけが、次に作る作品に効く。

## いま何のために読んでいるか

| 目的 | 期日 |
|---|---|

| AIクリエイターズマーケット2026 出展作 | 2026-11-07 |

だから当面のノートは**「調和」がどう作られてきたか**に寄る。テーマが変わればノートの寄せ方も変える。

## ノートの書き方

1ファイル1作品。`notes/YYYY-MM-DD-<作家>-<作品>.md`。中身は4つだけ:

1. **事実** — 作者・年・素材・寸法・所蔵。所蔵館の一次データから取る。
2. **作者自身の言葉** — 手紙・声明・カタログ。本人が何を狙ったと言っているか。無ければ「無い」と書く。
3. **どう成立しているか** — 構造の分解。色・線・配置・視線の運び。分解の粒度は「同じ手を自分で打てるか」で決める。
4. **自分の作品にどう使うか** — 具体的な手。抽象語（「バランスを意識する」等）は書かない。

**出典URLを本文に必ず置く**。手元の知識だけで書いた行は、書かない。
実物を見ていない作品は「実物未見」と明記する。図版と museum text から言えることだけ書く。
