# ノク

ナイジェリア中部、現カドゥナ州南部・ジョス高原南西の村落（Wikidata
[Q108908650](https://www.wikidata.org/wiki/Q108908650)、"Archeology village"）。座標は同項目の値
（北緯9.4897 東経8.0238）。

考古学が「ノク文化」「ノク彫刻」と呼ぶ括りは、この村の近郊で1928年に錫鉱採掘中に最初のテラコッタ断片
（猿の頭部像）が出土し、1943年に別の断片（通称ジェマ・ヘッド）が同じくこの一帯の錫鉱山で見つかったこと
に由来する地名（[National Geographic](https://www.nationalgeographic.com/history/article/nigeria-nok-terra-cotta)、
二次情報）。出土そのものはノク村周辺だけでなく中部ナイジェリアの広い範囲（約78,000平方キロメートル）に
及ぶが、地名としてのノクが型地名（type site の由来地）として使われている。
