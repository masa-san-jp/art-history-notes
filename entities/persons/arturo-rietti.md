# アルトゥーロ・リエッティ / Arturo Rietti

1891年の第一回ブレラ三年展公式カタログに、トリエステ出身者として掲載される画家。286番《Ritratto》、288番《Studio》、312番《Ritratto》を出品し、286・288番はパステルである。本項は展覧会記録に限定する。
