# ルイージ・コンコーニ《N. 317》

油彩・キャンバス、102×104cm、1890–1891年。ブレラ展ガイドは、1891年の第一回ブレラ三年展に出品された本作を
ミラノ市立近代美術館（Civica Galleria d'Arte Moderna di Milano）所蔵として記録する。公式カタログ本文は、Sala R–Sの317番を
「Conconi Luigi di Milano」の出品作として掲載する。作者は題名の代わりにカタログ番号を用いたため、作品ラベルは《N. 317》とする。
同時代の批評や後年資料は、墓地で母親の墓を訪れる二人の孤児を描いた作品として説明するが、作品の独立典拠IDは未確認である。
