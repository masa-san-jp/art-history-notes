# エンリコ・カッシ / Enrico Cassi

クアッソ・アル・モンテ生まれ、ミラノで没したイタリアの彫刻家。オルセー美術館は1863〜1913年の人物資料として、
イタリア人彫刻家であることを記録している。イタリア文化財カタログも、墓碑作品の作者としてカッシを登録している。

1891年の第一回ブレラ三年展では、公式カタログの14番に《Emigrata》を出品した。本項では、この展覧会での出品関係を記録するが、
カッシをイタリア分割主義の構成員とは位置づけない。
