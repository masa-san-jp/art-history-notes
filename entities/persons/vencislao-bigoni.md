# ヴェンチスラオ・ビゴーニ / Vencislao Bigoni

1891年の第一回ブレラ三年展公式カタログに、モデナ出身者として掲載される出品者。612番《Gli amatori》を出品した。本項は展覧会記録に限定する。カタログ本文の綴りを主記録とし、索引の「Venceslao」も別名に残す。
