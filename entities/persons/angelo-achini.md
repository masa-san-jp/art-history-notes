# アンジェロ・アキーニ / Angelo Achini

ミラノを中心に活動したイタリアの画家。油彩、水彩、版画など複数の技法を用い、風景、肖像、歴史画を制作した。

1891年の第一回ブレラ三年展では、公式カタログの102番《Ritratto》、579番《Inverno》を出品した。本項では、この展覧会での出品関係を記録するが、アキーニをイタリア分割主義の構成員とは位置づけない。
