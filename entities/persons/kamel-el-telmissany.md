# カーメル・エル=テルミサーニ

エジプトの画家・映画作家（1915年5月15日カイロ北方カリュービーヤ県生〜1972年3月3日ベイルート没、
Wikidata [Q12234337](https://www.wikidata.org/wiki/Q12234337)、国籍はP27でエジプトQ79）。1925年に
家族でカイロへ移り、1930年にエル=サイディーヤ中等学校で修了資格を取得。獣医学部に進んだが1941年に
中退し美術へ転じた（[Wikipedia英語版](https://en.wikipedia.org/wiki/Kamel_el-Telmissany)、二次情報）。

1939年、ジョルジュ・エネイン（[person/georges-henein](georges-henein.md)）、ラムセス・ユーナーン
（[person/ramses-younan](ramses-younan.md)）とともに[movement/art-et-liberte](../movements/art-et-liberte.md)
（アール・エ・リベルテ）の創設メンバーとされる（同記事）。同グループでの活動は約10年で、その後
映画製作に転じた。movement の `kind`（self-declared）・`founding_control` 判定の根拠人物として置いた
stub（`docs/schema.md` の person 作成基準1）。
