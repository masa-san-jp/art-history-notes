# エツィオ・チェッカレッリ / Ezio Ceccarelli

1891年の第一回ブレラ三年展公式カタログに、モンテカティーニ（ヴァル・ディ・チェチナ）出身者として掲載される彫刻家。623番《Ritratto》を出品した。本項は展覧会記録に限定する。なお、索引には同じ623番をダニエリ・バッサーノにも割り当てる記載があるが、本文の作者表記はチェッカレッリである。
