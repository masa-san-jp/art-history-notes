# ジュゼッペ・オーミオ《Matin sur les Alpes》

Database of Modern Exhibitionsは、1907年パリ展のSalle A（Rotonde）45番を《Matin sur les Alpes
[Morning on the Alps]》、油彩として記録する。人物ページでも同じ作品がオーミオの出品作として確認できる。
制作年、寸法、現所在は未確認であり、既知の《Labour alpestre / Mattino alpestre》とは別のカタログ作品として扱う。
