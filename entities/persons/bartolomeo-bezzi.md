# バルトロメオ・ベッツィ / Bartolomeo Bezzi

トレンティーノ出身のイタリアの画家。ブレラ美術アカデミーで学び、ミラノ、ヴェネツィアなどで活動した。主に風景画で知られる。

1891年の第一回ブレラ三年展では、公式カタログの70番《Lido》と220番《Quiete》を出品した。本項では、この展覧会での出品関係を記録するが、
ベッツィをイタリア分割主義の構成員とは位置づけない。
