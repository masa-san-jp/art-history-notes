# カトマンズ / Kathmandu

ネパールの都市（Wikidata [Q3037](https://www.wikidata.org/wiki/Q3037)、北緯27.71 東経85.32、
Getty TGN 1083294）。

[movement/newar-art](../movements/newar-art.md) の `originated_in` として参照する。ルービン美術館
Project Himalayan Art の用語集は、ネワールを「カトマンズ盆地（Kathmandu Valley）の伝統的な
住民」と定義する。

**未確認**: 本KBが参照するのは盆地（Kathmandu Valley）という広がりであって市域ではない。
パタン（ラリトプル）・バクタプルを含む3市が同じ盆地にあり、工房もそれぞれに存在した。
盆地を単位とする place を別に立てるべきかは未検討。なお本KBの
[place/patan](patan.md) は**インド・グジャラート州のパタン**であって、ネパールのパタンではない。
