# 第一回ブレラ三年展 / First Brera Triennale

1891年5月6日に開幕し、7月12日に閉幕した、ミラノのブレラ王立美術アカデミーを母体とする展覧会。Brera Guideは、
ミュンヘン展との作品受け入れ協定により、閉幕を7月12日まで延期できたと説明している。公式カタログの題紙は
「R. Accademia di Belle Arti di Brera」「Prima esposizione triennale 1891」と記し、本文はSala Aから
複数の展示室・Porticoを区分して出品を掲載する。

展示室ごとの完全な出品者・作品対応は未整理である。本項では、公式カタログで作者と作品名を
確認できた363作家606件を作品エンティティから参照する。これはカタログ全体の出品作数ではなく、現時点で個別化した範囲である。
このうちダヴィデ・カランドラの3件、エンリコ・ブッティの1件、エンリコ・カッシの1件、マリオ・サルヴィーニの1件、アントニオ・ベッツォラの2件、ドメニコ・ギドーニの3件、アレッサンドロ・ラフォレの1件、アキッレ・サラタの1件、アキッレ・アルベルティの1件、ウルバーノ・ノーノの2件、エルネスト・バッツァーロの1件、フランチェスコ・ポルツィオの1件、ヴィンチェンツォ・ロッサーノの1件、アンドレア・マルファッティの1件、グイリエルモ・グイデッティの1件、ジョヴァンニ・マイヤーの1件、エミリオ・マルシリの2件、フェッルッチョ・クレスピの1件、フィリッポ・チファリエッロの1件は彫刻作品の展覧会記録であり、これらの作家をイタリア分割主義の構成員とは位置づけない。
ポンペオ・マリアーニの2件、ジュゼッペ・フェッラーリの1件、ルイジ・セッラの2件は、パステル、エッチング、素描などの出品記録として扱い、個別作品への分解やイタリア分割主義への所属は推定しない。
