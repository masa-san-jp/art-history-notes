# イノチェンテ・フランチェスキーニ / Innocente Franceschini

1891年の第一回ブレラ三年展公式カタログに、ヴィチェンツァ出身者として掲載される彫刻家。617番《Vecchio buio》を出品した。本項は展覧会記録に限定する。
