# 図画署 / Dohwaseo

朝鮮王朝の官署。国家が必要とする絵画制作（御真＝国王肖像、儀軌＝国家儀礼の記録画、地図など）を
一手に担った。Wikidata [Q16181137](https://www.wikidata.org/wiki/Q16181137) の `P31`（instance of）は
`government agency`（Q327333）。`P749`（parent organization）は礼曹＝예조
（[Q17192768](https://www.wikidata.org/wiki/Q17192768)、朝鮮王朝の六曹の一つ）——礼曹に属する
官署である（「도화서는 예조에 소속된 종6품 아문」우리역사넷「도화서와 화원」）。

## 定義と範囲

朝鮮建国当初から「국초부터 국가적 회사를 관장하기 위하여」（우리역사넷）前身の図画院（도화원）が
設置され、その後「1463년부터 ≪經國大典≫이 편찬되었던 1469년 사이 어느 때인가」（同上）、あるいは
「1470년(성종 1)」（한국민족문화대백과사전「도화서」）、あるいは「1471년(성종 2) 이후」
（sillokwiki「도화서」）、あるいは「세조(재위 1455~1468) 말경」（월간미술事典「도화서」）と、
出典によって記載が割れたまま図画署へ改称された。改称理由は「화원의 격을 낮추어 조정한 결과」
（우리역사넷）——**画員の格を下げる調整の結果としての改称**だったとされる。

組織規模は『経国大典（경국대전）』に規定がある。提調（제조、礼曹判書の兼任が通例）1人・別提（별제）
2人・画員（화원）20人・画学生徒（화학생도、養成生）当初15人。生徒定員は1746年（英祖22）に15人から
30人へ倍増した（ko.wikipedia「도화서」）。画員の官品は種6品 善畵（선화）1人・種7品 善繪（선회）1人・
種8品 畵史（화사）1人・種9品 繪史（회사）2人という雑職（잡직）で、「화원은 천한 공장과 다를 바
없어」（우리역사넷／한국민족문화대백과사전「도화서」）低い身分に位置づけられていた。

画員は中人層以下から「取才（취재）」という技能試験で採用された。試験科目は竹・山水・人物・翎毛・
花草の5科目のうち2科目を選択し、竹を1等、山水を2等、人物・翎毛を3等、花草を4等として評価する
（우리역사넷）。取才は3か月ごとに実施されたとする記述もある（월간미술事典）。

代表的な画員に安堅（Q741512とは別人。山水画「夢遊桃源図」）・金弘道・申潤福がいる
（en.wikipedia "Dohwaseo"）。これらの担い手個々の一次資料には当たっていない。
`docs/schema.md` の person 作成基準（今回の org の time/space の根拠になる／2エンティティを
繋ぐ／作品を分解して読んだ）のどれにも単独では当たらないため、本文に名前を書くだけに留める。

## kind の判定 — なぜ movement ではなく org としたか、継承の形はどうだったか

### 1. 継承の形を軸ごとに見る

| 軸 | 図画署 | 出典 |
|---|---|---|
| 官職 | **非常に強い**。『経国大典』に規定された継続的な官署で、礼曹の下に置かれ、種6品衙門として制度化されていた。狩野派の奥絵師・土佐派の絵所預と並ぶ、あるいはそれ以上に強い制度的実体 | 우리역사넷／한국민족문화대백과사전「도화서」 |
| 血縁 | **確認できる。ただし単一家による官職独占ではない**。16世紀に李上佐（이상좌）の家系が3代（本人→息子・李崇孝／李興孝→孫・李楨）にわたり画員を輩出した「代表的画員家門」とされる。17世紀には仁同張氏・陽川許氏、18〜19世紀には慶州金氏・開城金氏が画員を輩出する家系として現れる。開城金氏は金応煥を祖に、甥の金得臣・金碩臣（のち養子）・金良臣、婿の李命基・張漢宗、さらに金得臣の息子・金建鍾／金秀鍾／金夏鍾へと少なくとも3代・18世紀半ばから19世紀にわたり画員を輩出したことが具体的に辿れる | 우리역사넷「도화서와 화원」（李上佐家）／월간미술事典（仁同張氏・陽川許氏・慶州金氏・開城金氏）／우리역사넷「김득신」（開城金氏の系譜） |
| 工房 | 図画署内部に画学生徒という官立の養成制度があった（定員15→30人）。ただし狩野派のような私的な家伝の粉本・画法伝承の記録には当たっていない | ko.wikipedia「도화서」 |
| 地縁 | **無い**。「図画署」という名称は機能（図画を署る）の記述であり、浙派のような地名由来ではない | （名称の構成自体から） |
| 様式 | **確認できない**。図画署という組織単位に紐づく共通の画風は史料に現れない。安堅・金弘道・申潤福はそれぞれ個別の画風・画題（山水画、風俗画など）で美術史上区別されており、「図画署様式」という括りは無い | en.wikipedia「Dohwaseo」 |

**画員の地位が世襲されたか**という論点への回答: 一部世襲された。ただし全面的な世襲ではない。
朝鮮初期には奴僕出身の李上佐や塩田業者の息子・崔涇のように、家系と無関係に画員になった例がある
一方、朝鮮中期以降は「가계적(家系的)으로 서로 관계를 가지는 화원 집안」（同一家系内で技能が
継承される画員家門）が明確に現れる（우리역사넷「도화서와 화원」）。ただし採用は取才という試験を
介した制度であり続け、金弘道のように家系の中で最初の画員という例も記録されている
（WebSearch経由・二次情報、金弘道の家系についての一次資料には当たっていない）。

### 2. org と判定した理由

Wikidata の `P31` は `government agency`（Q327333）で、`P749`（parent organization）に礼曹を
挙げる——機能的にも制度的にも国家官署そのものである。狩野派・土佐派・琳派・浙派はいずれも
「画風・画系という集合的な芸術実践の括り」に何らかの名（家名・後代の呼称）が付いた対象だったが、
図画署にはそれに相当する名——「図画署派」のような様式的括り——が確認できない。担い手（安堅・
金弘道・申潤福）は個別の画風で語られ、組織としての図画署に共通の様式は帰属していない。

`docs/schema.md` の型定義に従えば、`movement` は「担い手の集合が歴史的に特定できる」集合的芸術実践の
括りであり、`org` は「組織。美術館・アカデミー・画商・工房・幕府」——図画署は礼曹に従属する国家の
行政機関そのものであり、後者に当たる。よって `movement` ではなく `org` として作った。`org` には
`kind`（4値）の必須項目が無く、本ファイルにも設定していない。

### 3. 仮説への適合性 — **対象外。ただし「制度」の語を3つに割る必要が明確になった**

`overviews/japan-school-types.md` の仮説は「制度的な継承がある→当事者由来の呼称→`lineage-school`／
制度的な継承がない→後代由来の呼称→`retrospective`」という、`movement` の `kind` を分ける二分法
だった。図画署は `movement` ではなく `org` と判定したため、この二分法をそのまま適用する対象では
ない——これがまず言えること。

同じ概要文書は図画署を「官の画院という制度は強いが、家の連続とは切れているかもしれない」という
反証候補として挙げていたが、**この予想は外れた**。血縁は切れていなかった。李上佐家・開城金氏など、
複数世代にわたって画員を輩出した家系が実在する。**事実に合わせるなら、予想を訂正する必要がある**:
図画署は「制度は強いが血縁が無い」例ではなく、「**制度も血縁もあるが、単一の家が官職・様式を
占有する構造にはならなかった**」例だった。

その理由は2つに分解できる。第一に、官職そのもの（画員という枠）は取才という開かれた試験を通じて
複数の中人系画員家門が並行的に供給する構造であり、狩野派の奥絵師・土佐派の絵所預のように「一つの
家が一つの官職・称号を代々占有する」形にはならなかった。第二に、図画署という組織単位に帰属する
共通の画風・様式が確認できず、狩野派・浙派のような「様式による括り」を生む土台が無かった。

ここから、仮説が前提していた「制度」という語は、少なくとも**官職の継続・血縁の継続・様式的
同一性の継続という3つの軸に分けて扱う必要がある**と言える。図画署は「官職＝強い・血縁＝複数家の
並行という形で存在・様式＝欠如」という、狩野派・土佐派（官職＝強い・血縁＝単一家・様式＝強い）とも
浙派（官職＝弱い・血縁＝無い・様式＝括りの核）とも異なる第4の組み合わせを示した。官職と血縁が
両方とも強く存在していても、様式的な同一性が欠ければ「派」（`movement`）は生まれない、という
ことがこの1件から言える。**ただし、この一般化は図画署1件のみからのもので未検証**。

## 時間

前身の図画院は「国初から」設置されたとされるが（우리역사넷）、具体的な年は史料に明記されて
いない。朝鮮建国が1392年（太祖元年）であることから、世紀精度で `13XX`（14世紀）とした。
図画署への改称年は出典間で一致しない——1463〜1469年のどこか（우리역사넷）、1470年・成宗元年
（한국민족문화대백과사전）、1471年・成宗2年以降（sillokwiki）、世祖末年頃（월간미술事典）、
英語版Wikipediaは「睿宗代に改称」とする——いずれも1460年代後半〜1471年ごろに収斂するが、
単一の年を特定できないため `time.end` は使わず `display` に幅として記録した。

**未確認**: 廃止年。월간미술事典は「朝鮮末期に廃止されたが正確な時期は明らかになっていない」とし、
「18世紀末から市場経済の活性化とともに絵画流通も活発化し、19世紀末頃に国家組織の一部として存続
しつつ瓦解したとみられる」という推測を述べるのみ。別の記述は「韓末（朝鮮末期）まで存続」ともする。
具体的な年を特定する一次資料には当たっていない。`time.end` は `null`（不明）のままにした。
