# エドゥアール・メンタ / Edouard Menta

ジュネーヴ生まれ、ニースを活動拠点とした画家。美術館・展覧会資料は、風景画から風俗画や肖像画へと領域を広げた画家として記録している。

1891年の第一回ブレラ三年展では、公式カタログの63番《Al piatto d’oro》を出品した。本項では、この展覧会での出品関係を記録するが、
メンタをイタリア分割主義の構成員とは位置づけない。
