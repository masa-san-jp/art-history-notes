# オレステ・ラボ / Oreste Labò

1891年の第一回ブレラ三年展公式カタログに、ピアチェンツァ出身者として掲載される彫刻家。498番《Morte di Torquato Tasso》を出品した。本項は展覧会記録に限定する。
