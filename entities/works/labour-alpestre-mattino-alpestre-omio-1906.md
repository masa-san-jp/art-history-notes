# ジュゼッペ・オーミオ《Labour alpestre / Mattino alpestre》

Database of Modern Exhibitionsは、1907年パリ展の46番を《Labour alpestre [Alpine Ploughing]》として記録する。
同データベースの人物ページと作品目録は、1906年作《Mattino alpestre》を対応候補として示す。国立ルーチェの作品目録では、
オーミオの《Mattino alpestre》を1906年作、整理番号9381として掲載する。

同時代資料の後年紹介は、本作をローマの国立近代美術館の公的所蔵作品として言及するが、現行館内データベースでの個別照合は
未確認である。そのため、ここでは題名の異同と所蔵情報の確認課題を残し、1907年出品記録との対応を記録する。
