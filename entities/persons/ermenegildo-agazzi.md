# エルメネジルド・アガッツィ / Ermenegildo Agazzi

1891年の第一回ブレラ三年展公式カタログに、マペッロ出身者として掲載される出品者。442番《Novembre - Studio dal vero》を出品した。本項は展覧会記録に限定する。
