# スパルタコ・ヴェーラ / Spartaco Vela

スイスの彫刻家ヴィンチェンツォ・ヴェーラの息子で、トリノ生まれの画家。ブレラで学び、風俗画、人物画、風景画を制作した。

1891年の第一回ブレラ三年展では、公式カタログの95番《Locus olim publice Veneri damnatus》を出品した。本項では、この展覧会での出品関係を記録するが、ヴェーラをイタリア分割主義の構成員とは位置づけない。
