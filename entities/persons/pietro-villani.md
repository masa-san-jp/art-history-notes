# ピエトロ・ヴィッラーニ / Pietro Villani

ノチェーラ・インフェリオーレに生まれ、ミラノで没したイタリアの画家（1866–1935）。画家略歴資料は、
ミラノのブレラ美術アカデミーで学び、1891年のブレラ展に「Ritratto di Signora」と
「In Val d’Intelvi」を出品したと記録する。

1891年の第一回ブレラ三年展公式カタログでは、「Villani Pietro di Nocera Inferiore (Salerno)」として、
572番の「In Val d’Intelvi」を出品したことが確認できる。本項ではこの出品記録を作品エンティティに分離した。
