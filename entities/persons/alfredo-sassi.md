# アルフレード・サッシ / Alfredo Sassi

ミラノ生まれのイタリアの彫刻家。Società Umanitariaは1869〜1952年の彫刻家として、ブレラで学び社会教育にも携わった経歴を記録している。

1891年の第一回ブレラ三年展では、公式カタログの109番《Poesia》を出品した。本項では、この展覧会での出品関係を記録するが、
サッシをイタリア分割主義の構成員とは位置づけない。
