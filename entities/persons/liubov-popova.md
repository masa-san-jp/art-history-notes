# リュボーフィ・ポポワ / Liubov Popova

## 構成主義での位置

ポポワは、ロシア前衛の抽象絵画から、演劇・衣服・印刷などの応用芸術へ活動を広げた作家。MoMAは、
彼女を構成主義者として紹介し、1921年の《5×5=25》にも参加したと記録している。
本KBでは、絵画の様式だけでなく、構成主義の集団的実践と生産への移行に関わった人物として
[`movement/constructivism`](../movements/constructivism.md)へ接続する。

## VKhUTEMASと応用芸術

1920年代初頭、VKhUTEMASとモスクワの国立芸術文化研究所（INKhUK）に関わり、色彩とデザインを教えたと
MoMAは説明している。構成主義の理論を実際の教育・工業生産へ移す制度的接点として、
[`org/vkhutemas`](../orgs/vkhutemas.md)を`member_of`で記録する。

## 共同制作

1924年の雑誌『LEF』第2号では、ロトチェンコ、ステパノワとともに誌面と抽象幾何学的な布地パターンに
関わった。作品側の典拠と3人の作者関係は[`work/lef-no-2-1924`](../works/lef-no-2-1924.md)にまとめる。
