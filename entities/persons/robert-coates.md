# ロバート・コーツ

抽象表現主義の担い手ではなく、**「abstract expressionism」という語を米国の美術批評に持ち込んだ側**の
人物として置いた stub（movement/abstract-expressionism の `naming.named_by` と `kind` 判定の根拠に
なるため作成——`docs/schema.md`「person をいつ作るか」基準1）。

生没年は Wikidata [Q9069789](https://www.wikidata.org/wiki/Q9069789)（precision 11・日単位、
1897年4月6日〜1973年2月8日）。1937年から1967年まで『ニューヨーカー』誌の美術評を担当した批評家・
小説家。1946年、ハンス・ホフマンの絵画18点を扱った同誌の批評記事の中で「abstract expressionism」
という語を用いたとされる（[英語版Wikipedia「Robert Coates (critic)」](https://en.wikipedia.org/wiki/Robert_Coates_(critic))、
[英語版Wikipedia「Abstract expressionism」](https://en.wikipedia.org/wiki/Abstract_expressionism)、
いずれも二次情報）。**未確認**: 当該記事そのもの（1946年『ニューヨーカー』誌のホフマン評、正確な
掲載日・記事題名）の実物には今回到達できていない。

なお同語自体はコーツの造語ではない。英語版Wikipediaは、ドイツで1919年に雑誌『Der Sturm』がドイツ
表現主義を指して用いたのが最初とされ、1929年にはアルフレッド・バーがカンディンスキーの作品を評する
のに用いたと記す（同記事、二次情報）。コーツの1946年の用法は、この語を**米国の抽象画（ポロック・
デ・クーニングらを含む戦後ニューヨークの動向）に転用した最初期の例**という位置づけになる。
