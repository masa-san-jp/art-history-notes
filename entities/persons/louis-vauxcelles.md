# ルイ・ヴォークセル

キュビスムの担い手ではなく、**「cubisme」という語を最初に書いた側**の人物として置いた stub
（movement/cubism の `naming.named_by` と `kind` 判定の根拠になるため作成——`docs/schema.md`
「person をいつ作るか」基準1）。

フランスの美術批評家。1908年11月14日付『Gil Blas』紙付録に掲載したジョルジュ・ブラックの
カーンワイラー画廊での個展評で、ブラックの絵を「幾何学的図式に、立方体（cubes）に還元する」と
書いた一文が、この語の最初の使用として広く引用される（詳細と出典は
[movement/cubism](../movements/cubism.md#kindの判定)側にまとめた）。同年より前の1905年、
別の展覧会評でマティスらの作品を「野獣（フォーヴ）」と評したことでもフォーヴィスムの命名者として
知られ、この人物は同時期に2つの様式名の起点になっている
（[Wikipedia「Fauvism」](https://en.wikipedia.org/wiki/Fauvism)、二次情報）。

**未確認**: 本項では生没月日・経歴の詳細までは調べていない（movement/cubism の根拠として
必要な範囲に留めた）。
