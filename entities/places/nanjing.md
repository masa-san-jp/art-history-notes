# 南京

金陵八家（`movement/jinling-eight-masters`）の結節点として置いた stub。座標は Wikidata Q16666 の
`P625` の値。「金陵」は南京の旧称（六朝期の建康、明代の応天府などとともに Wikidata が記録する
複数の旧称の一つ）で、金陵八家という呼称自体がこの旧称を採っている。
