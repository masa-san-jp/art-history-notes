# アレッサンドロ・ヴァノッティ / Alessandro Vanotti

1891年の第一回ブレラ三年展公式カタログに、ミラノ出身者として掲載される画家。249番《Ritratto》、250番《Ritratto di Signora》（水彩）、251番《Ritratto di Signora》、252番《Te laudamus Domine》を出品した。本項は展覧会記録に限定する。
