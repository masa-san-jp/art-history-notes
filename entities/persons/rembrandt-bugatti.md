# レンブラント・ブガッティ / Rembrandt Bugatti

ミラノに生まれたイタリアの動物彫刻家。Treccaniとベルリン国立美術館は、動物を主題とする
彫刻家としての活動を記録している。

1907年パリ展の一次カタログ序文は、同展に参加する彫刻家の一人としてブガッティを挙げる。本文は、
展示室Cにブガッティの彫刻が置かれていたことにも触れている。個別の作品番号・題名を確定できないため、
ここでは展覧会参加と展示場所の記述のみを記録し、作品エンティティは作成していない。
