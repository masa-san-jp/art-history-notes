# ピエロ・フォカルディ《Printemps / Primavera》

Database of Modern Exhibitionsは、1907年パリ展のSalle A（Rotonde）7番を《Printemps [Spring]》、油彩として記録する。
専門資料は同作をイタリア語題《Primavera》として、フォカルディの同展出品作群に含める。制作年、寸法、現所在は確定していない。
