# ピエロ・フォカルディ《Baigneurs dans le Lac》

Il Divisionismoは本作を1906年制作、油彩・キャンバス、61.5×151cmとして掲載し、イタリア語題を
《Bagnanti al sole》と併記する。1907年パリ展のDatabase of Modern Exhibitionsでは、フォカルディの
第2番が《Baigneurs dans le Lac》として記録されており、同じ題名・作者の作品として対応させる。
