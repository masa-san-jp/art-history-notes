# ピエール・ボウシェルレ

チュニス生まれのフランス人画家（1894年4月11日 – 1988年11月22日）。オリエンタリスト・風景画家
（[fr.wikipedia.org/wiki/Pierre_Boucherle](https://fr.wikipedia.org/wiki/Pierre_Boucherle)、
二次情報）。第二次世界大戦後にチュニジアへ戻り、他の画家とともに「グループ・デ・キャトル
（4人組）」を結成、これが「グループ・デ・ディス（10人組）」を経て1949年に
「チュニス派」（[movement/ecole-de-tunis](../movements/ecole-de-tunis.md)）を名乗った
（同資料）。チュニス派の初代会長（premier président）を務めた
（[harissa.com](https://harissa.com/news555/fr/pierre-boucherle-fondateur-de-lecole-de-tunis)、
二次情報）。1948年2月5日には画家ヤヒヤ・トゥルキ（[person/yahia-turki](yahia-turki.md)）と連名で
フランス保護領の統領（Résident général）宛に美術予算の増額を求める書簡を送っている
（[Fiker Institute, Mouadh Elarbi, 2024年4月](https://www.fikerinstitute.org/publications/lecole-de-tunis-the-arts-in-post-independence-tunisia)、
二次情報）。

movement/ecole-de-tunis の `kind` と `founding_control` の根拠になる中心人物として置いた stub
（`docs/schema.md` の person 作成基準1）。フランス人でありながらチュニジア独立（1956年）後も
「自らの生まれた国を去らない」ことを選び、ミュチュエルヴィル高校や美術学校で教え続けた
（[fr.wikipedia.org/wiki/Pierre_Boucherle](https://fr.wikipedia.org/wiki/Pierre_Boucherle)）。
一方でチュニス派の会長職は独立と同じ1956年にヤヒヤ・トゥルキへ引き継がれている（詳細は
movement/ecole-de-tunis 本文）。
