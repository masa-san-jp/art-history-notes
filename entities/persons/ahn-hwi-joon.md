# 安輝濬 / Ahn Hwi-joon

[movement/an-gyeon-school](../movements/an-gyeon-school.md) の `naming.named_by` と `kind`
判定の根拠として置いた stub（`docs/schema.md` の「person をいつ作るか」基準1）。

ソウル大学考古人類学科卒、米ハーバード大学大学院で美術史学の修士・博士号取得。ホンイク大学教授・
ソウル大学博物館長・ソウル大学考古美術史学科教授を経て2006年定年退職。文化財委員長・韓国美術史学会長
なども歴任した韓国美術史学の基礎を築いた研究者。2026年7月20日、86歳で死去
（<https://www.khan.co.kr/article/202607201829001/>）。

主著『韓国絵画史（한국회화사）』（一志社、1980年）が、韓国絵画史研究者にとって必須資料とされる
（同記事）。한국민족문화대백과사전「안견파」（自ら執筆者として名を連ねる項目）は「'안견파'라는
용어는 안휘준…에 의해 명명되었다」（「安堅派」という用語は安輝濬によって命名された）と明記する
（<https://encykorea.aks.ac.kr/Article/E0069639>）。**未確認**: この用語を最初に体系的に用いた
文献が1974年の論文「安堅과 그의 画風—夢遊桃源図を中心으로」（『震檀学報』38）か、1980年の
『韓国絵画史』かは、当たった出典からは特定できない。
