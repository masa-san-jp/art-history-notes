# サンテ・カルカーニ / Sante Calcagni

ロニーゴ出身のイタリアの画家。ヴェネツィアで学び、人物画や風俗画を中心に制作し、ブレラやミラノの展覧会にも参加した。

1891年の第一回ブレラ三年展では、公式カタログの76番《Nel secolo scorso》を出品した。本項では、この展覧会での出品関係を記録するが、
カルカーニをイタリア分割主義の構成員とは位置づけない。
