# 李禹煥

韓国生まれの美術家（1936年6月24日 –、Wikidata [Q399775](https://www.wikidata.org/wiki/Q399775)、
生年月日は precision 11＝日単位。国籍は韓国）。1969年、関根伸夫の《位相—大地》（1968年）を現象学的な
視点から評価・理論づけた論考「世界と構造ー対象の崩壊（現代美術ノート）」（『デザイン批評』9号、
1969年6月）を発表し、以後この評価軸が [movement/mono-ha](../movements/mono-ha.md) 形成の中心的な
理論的支柱になった。Getty AAT [300417405](https://www.getty.edu/vow/AATFullDisplay?find=mono+ha&logic=AND&note=&english=Y&prev_page=1&subjectid=300417405)
は「1968年に李禹煥と関根伸夫によって始められた日本の芸術運動」とし、両者を運動の起点に置く。

日本美術オーラル・ヒストリー・アーカイヴの本人インタビュー
（[oralarthistory.org](https://oralarthistory.org/archives/interviews/lee_u_fan_02/)）で、「もの派」という
呼称について「誰が言ったのか全然分かりません」「たぶん69年終わり頃出た」と語り、命名者・命名時期を
自らも特定できないと述べている。また当時この呼称で呼ばれた当事者として「すごく嫌だった」とも語る
（詳細は movement/mono-ha の `naming` を参照）。movement/mono-ha の `kind` 判定・`naming` 判定・
`created_by` の直接の根拠になるため作成した。
