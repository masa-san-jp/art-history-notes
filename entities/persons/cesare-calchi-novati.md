# チェーザレ・カルキ・ノヴァーティ / Cesare Calchi Novati

1891年の第一回ブレラ三年展公式カタログに、ミラノ出身者として掲載される出品者。261番《Fiori》、262番《Garofani》、430番《Primavera》を出品した。本項は展覧会記録に限定する。
