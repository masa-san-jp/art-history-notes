# アルベルト・マラスピーナ侯爵 / Alberto Malaspina Marchese

1891年の第一回ブレラ三年展公式カタログに、ピサ出身者として掲載される画家。506番《Calma di mare》、507番《Colline toscane》、508番《Marina a Nervi》を出品した。本項は展覧会記録に限定する。
