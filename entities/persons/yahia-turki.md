# ヤヒヤ・トゥルキ

チュニジア人画家（1903年イスタンブール生 – 1969年3月1日没）。「チュニジア絵画の父」と呼ばれる
（[en.wikipedia.org/wiki/Yahia_Turki](https://en.wikipedia.org/wiki/Yahia_Turki)、二次情報）。
父はジェルバ島出身、母はトルコ人。1947年の「グループ・デ・ディス（10人組）」の一員であり、
1948年に「チュニス派」（[movement/ecole-de-tunis](../movements/ecole-de-tunis.md)）の創設者の
一人となった（同資料）。1948年2月5日にはピエール・ボウシェルレ
（[person/pierre-boucherle](pierre-boucherle.md)）と連名でフランス保護領の統領宛に美術予算の
増額を求める書簡に署名している
（[Fiker Institute, Mouadh Elarbi, 2024年4月](https://www.fikerinstitute.org/publications/lecole-de-tunis-the-arts-in-post-independence-tunisia)、
二次情報）。1956年、チュニジア独立後にボウシェルレの後を継いでチュニス派の会長に就任し、死去する
1969年までその職にあった（[en.wikipedia.org/wiki/Yahia_Turki](https://en.wikipedia.org/wiki/Yahia_Turki)）。

movement/ecole-de-tunis の `kind` と `founding_control` の根拠になる中心人物として置いた stub
（`docs/schema.md` の person 作成基準1）。フランス人ボウシェルレから会長職を引き継いだ時期が
独立の年（1956年）と一致することが、チュニス派の意思決定構造の変化を示す一次的な手がかりに
なっている（詳細は movement/ecole-de-tunis 本文）。
