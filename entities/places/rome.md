# ローマ / Rome

イタリアの都市（Wikidata [Q220](https://www.wikidata.org/wiki/Q220)、北緯41.8931 東経12.4828、
Getty TGN 7000874）。

[movement/mannerism](../movements/mannerism.md) の `originated_in` として参照する。Getty AAT は
マニエリスムを「chiefly in Rome」で展開した様式と記す。1527年のローマ略奪で画家たちが各地へ
離散したことが、この様式がイタリア外へ広がる契機になったとされる。

**未確認**: 都市としての時間軸、およびマニエリスム以外の局面（古代・盛期ルネサンス・バロック）に
ついては未調査のまま。
